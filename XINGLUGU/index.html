关于 XINGLUGU

XINGLUGU 是一个 16-bit 像素风农场小游戏前端项目，视觉语言致敬 《星露谷物语》(Stardew Valley)：温暖大地色系、无抖色干净色块、1px 深色描边、像素字体与复古 RPG 界面。

纯 HTML / CSS / JavaScript 实现，无任何第三方依赖，字体本地打包，可直接在浏览器中运行。
