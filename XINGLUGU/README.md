# XINGLUGU · 像素农场物语

一个致敬《星露谷物语》(Stardew Valley) 的 16-bit 像素风农场小游戏前端项目。
**纯 HTML / CSS / JavaScript 实现，零第三方依赖，字体本地打包，双击 `index.html` 即可运行。**

![技术栈](https://img.shields.io/badge/stack-HTML%20%2F%20CSS%20%2F%20JS-ffcb00) ![无依赖](https://img.shields.io/badge/deps-none-brightgreen)

## 目录结构

```
XINGLUGU/
├── index.html           # 页面入口（主菜单 / 加载 / 游戏三屏）
├── css/
│   └── style.css        # 全部像素视觉样式（字体、按钮、对话框、HUD）
├── js/
│   ├── audio.js         # Web Audio 合成 8-bit 音效与循环 BGM（无音频文件）
│   ├── scene.js         # Canvas 像素农场场景引擎（菜单背景 + 游戏场景）
│   └── main.js          # 状态机与交互逻辑（菜单 / 加载 / 游戏 / 键盘 / 收获）
├── assets/
│   └── fonts/
│       ├── PressStart2P-Regular.ttf   # 英文像素字体（OFL）
│       └── Zpix.ttf                   # 中文像素字体「最像素」
└── README.md
```

## 如何运行

直接双击 `index.html` 在浏览器中打开即可（推荐 Chrome / Edge / Firefox 最新版）。
无需安装任何依赖，也无需启动本地服务器。

## 玩法说明

| 操作 | 效果 |
|------|------|
| `W A S D` / 方向键 | 农夫 4 方向自由移动（带碰撞检测） |
| 走到农田 + `空格` / `E` | 播种（-1 种子、-5 体力）或收获成熟作物（+10~20 G、-3 体力）|
| 走到商店（右下角小径尽头）| 按 `B` 打开种子商店 |
| `B` | 打开 / 关闭种子商店 |
| `M` | 开关音效 |
| `ESC` | 返回主菜单 |

### 游戏循环

1. 进入游戏：初始 `50 G` + `3 颗种子` + 任务"收获 3 个作物"
2. 走到农田空地 → 播种（消耗 1 颗种子 + 5 体力）
3. 等待约 16 秒/轮：作物从「种子 → 小芽 → 苗 → 开花 → 成熟金色」
4. 走到成熟作物 → 收获（+10~20 G、-3 体力）
5. 完成右上角任务 → 奖励 25 G + 自动分配新任务
6. 种子用完 → 到右下角小径尽头按 B 进商店买种子（5 G/颗）
7. 体力耗尽 → 自动恢复 + 弹窗提示休息

### 互动细节

- 走进成熟作物附近 → 顶部金色提示条"按 空格/E 收获"
- 走进空地附近 → 顶部提示"按 空格/E 播种"（没种子时提示"按 B 去商店买"）
- 走进商店附近 → 顶部提示"按 B 打开商店"
- 走进小鸡（< 60 像素）→ 小鸡会跑开（互动小彩蛋）
- 走进小猪（< 62 像素）→ 小猪"哼"叫一声（带冷却）并跑开
- 路过时小猪还会偶尔拱地（低头嗅）
- 点击农田中任一格 → 自动走过去并交互

## 设计语言（基于星露谷物语调研）

### 1. 16-bit 复古像素画风
- 受 SNES 时代启发的 2D 像素艺术：清晰、简化的形状，俯视视角。
- 所有图形由离散像素块构成（Canvas `fillRect` + 字符图元精灵），无矢量平滑。
- 动画简洁但富有表现力：作物生长分 5 阶段、农夫行走/弯腰双帧、鸡啄食双帧。

### 2. 温暖大地色系配色
- 核心色：草地绿 `#5ea24a`、泥土棕 `#8a5a32`、木纹 `#a0673c`、天空蓝 `#7ec8e3`。
- 点缀色（10%）：金盏黄 `#ffcb00`（CTA / 金币 / 成熟作物）、砖红 `#b04a3a`（屋顶 / 窗口标题）。
- 遵循星露谷的"无抖色（no dithering）"原则：纯色块、干净边界，营造 cozy 氛围。
- 深棕 `#3b2a1e` 做 1px 描边，让物体从背景中"弹"出来。

### 3. 像素字体
- **Press Start 2P**：经典 8-bit 英文像素字体（标题、数字、按键标注）。
- **Zpix（最像素）**：中文像素字体，正文与中文 UI 全部像素化。
- 两者均以 `@font-face` 本地打包，离线可用。

### 4. 复古 UI 元素
- **Chunky 像素按钮**：4px 深棕描边 + 底部实体投影，按下时下沉 5px（`steps()` 硬切动画）。
- **RPG 对话框**：深木底 + 点阵纹理 + 名字标签（◆ 爷爷）+ 打字机效果 + 闪烁 ▼ 继续键。
- **像素进度条**：斜纹填充（45° repeating-linear-gradient）模拟复古 loading 条。
- **点阵纹理**：`radial-gradient` 半色调点阵叠加，避免纯色平铺。
- **HUD**：日期 / 金币 / 体力斜纹能量条，深色半透明底。

### 5. 交互反馈与无障碍
- 所有交互 100ms 内反馈：按钮按压、音效合成（点击 / 开始琶音 / 收获叮当 / 金币声）。
- 焦点可见（`:focus-visible` 金色光圈）、触摸目标 ≥44px、`prefers-reduced-motion` 降级动画。
- 出错保留输入：操作说明 / 关于对话框为模态，遮罩点击或 ESC 可关闭。

## v2 更新日志

- **移动控制**：农夫支持 WASD / 方向键 4 方向自由移动；面向方向 4 套精灵（正面 / 背面 / 左侧 / 右侧）
- **碰撞检测**：基于脚部点的 AABB 碰撞，房子 / 树 / 围栏不可穿越
- **种植系统**：走到空地按 空格/E 播种，-1 种子 -5 体力；空地显示"种子"提示
- **收获升级**：走到成熟作物旁交互；保留点击交互作快捷方式
- **种子商店**：走到右下角小径尽头按 B 打开；买 1 / 5 颗种子（5 G/颗）
- **任务目标系统**：HUD 显示任务进度（"收获 3 个作物 (1/3)"），完成后奖励 25 G 自动派新任务
- **交互提示气泡**：根据农夫附近的可交互对象动态显示"按 空格/E 收获/播种/按 B 打开商店"
- **小鸡互动彩蛋**：走近小鸡 < 60 像素 → 小鸡跑开
- **加载动画健壮化**：setInterval + 绝对时间驱动，避免后台 tab 节流卡死

## v3 更新日志

- **新增小猪**：3 只粉红小猪分布在草地区，各自围绕 home 点悠闲散步；每 4 秒会拱地（低头嗅），玩家靠近 62 像素会跑开
- **小猪叫声**：`XLAudio.sfx.oink()` —— 锯齿波下行双音（210→110 Hz + 105→70 Hz），模拟猪哼；每只猪有 3.2 秒冷却
- **走路动画优化**：原腿部帧为左右歪斜两帧，改为俯视 RPG 经典「张开/合拢」两帧 + 1px 身体起伏（bob），更自然协调
  - walk1：腿左右张开（``..pp..pp..`` / ``..bb..bb..``）
  - walk2：腿并拢（``..pppp..`` / ``..bbbb..``）
  - 行走帧时身体根据 `f.animT` 同步 1px 上下浮动，影子保持贴地营造迈步感
