# Vibe Coding-Lab

这个仓库用于记录和整理我在 **Vibe Coding** 过程中完成的小型项目、前端 Demo 和实验性想法。在线作品集：[VibeCoding-Lab](https://fcy222fcy.github.io/VibeCoding-Lab/)。

主要用于：

* 尝试不同的产品想法
* 快速实现前端 Demo
* 练习 AI-assisted development
* 记录一些有趣的小实验

## 已有模块

| 模块 | 简介 |
| --- | --- |
| [TodoList](./todolist/) | Vue 3 待办清单，练习任务管理、筛选与本地保存。 |
| [TodoList React](./todolist-react/) | 用 React 实现的待办清单，便于对比两种前端开发方式。 |
| [食友后台管理](./management-system/shiyou-admin/) | 校园美食平台的后台管理原型，包含数据看板和业务管理页面。 |
| [XINGLUGU 像素农场](./XINGLUGU/) | 可移动、种植、收获的像素风小游戏。 |
| [AI 演进图谱](./model-atlas/) | 从模型篇开始梳理 AI 发展；首篇收录 OpenAI、Claude 与 DeepSeek，支持画布缩放和全屏探索。 |

各模块的运行方式见对应目录；作品集首页和 GitHub Pages 发布流程位于仓库根目录。项目以学习、实验和快速原型为主。

😈本项目由 Codex、Trae、WorkBuddy、zcode 等 AI Coding 工具友情提供算力（精神）支持。
